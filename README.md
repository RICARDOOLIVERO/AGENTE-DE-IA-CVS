TalentAI es un agente de cazatalentos automatizado orientado a perfiles de ingeniería informática, machine learning, data science e inteligencia artificial.
A partir de un CV cargado por el usuario, el sistema analiza en profundidad la experiencia profesional, el stack tecnológico, la especialización, la formación 
y el nivel de seniority del candidato , incluyendo competencias implícitas como liderazgo técnico o arquitectura de sistemas ,
y busca activamente oportunidades laborales (remotas, híbridas o presenciales) que encajen realmente con ese perfil.
Para cada puesto recomendado, genera una ficha con título, empresa, ubicación, modalidad, descripción del rol, justificación técnica del encaje y vías de aplicación,
ordenando los resultados de mejor a peor match. Si el CV tiene información incompleta o las coincidencias no son exactas, el agente lo señala de forma explícita 
en lugar de forzar recomendaciones poco fiables.
El flujo está pensado para ser de un solo paso: el usuario sube su CV una vez y recibe un análisis completo con recomendaciones accionables,
sin intervención manual adicional.
